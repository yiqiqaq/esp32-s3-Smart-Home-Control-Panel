# ESP32-S3 智能面板硬件清单与供电方案

本文档记录推荐硬件、功能、低压连接关系，以及成品和测试阶段的供电方式。当前显示方案为 Waveshare ESP32-S3-Touch-LCD-4.3C 一体板（实际在用板卡）；原 4.3 英寸 DSI 屏不纳入方案。

## 1. 供电方案

### 成品：接入市电

成品由市电供电：市电先进入**有安全认证、封闭式、隔离型 AC-DC 电源模块**，再由模块输出稳定的 5V DC 给 ESP32-S3 面板和低压控制侧。不能把交流市电直接接到 ESP32-S3、USB、GPIO、屏幕或低压继电器控制端。

推荐结构：

```text
市电输入
  → 合规的输入端子与支路保护
  → 封闭式隔离 AC-DC 电源（AC 输入 → 5V DC 输出）
  → 低压 5V 母线
      ├─→ ESP32-S3-Touch-LCD-4.3C
      └─→ 继电器/IO 模块（仅在其额定电压匹配时）
```

- 4.3C 板卡资料标注典型供电为 **5V / 450mA**。这不是整机电源额定值；还需计入背光亮度、外接模块和继电器线圈的最大电流。
- AC-DC 模块的输出电流应按所有 5V 负载的峰值电流相加，并留出工程余量。未确定继电器型号及实测峰值前，不锁定最终电源电流/功率型号。
- 继电器触点的灯具市电回路与面板低压供电/逻辑侧应按继电器模块规格保持隔离；不要为了“共地”而跨接隔离边界。
- 市电输入、保护器件、绝缘距离、阻燃外壳、散热、应力释放和高低压分区必须按当地法规及器件认证设计。市电施工由具备相应资质的电工完成。

### 前期开发和测试：5V USB

测试阶段通过 USB-C 接入稳定 **5V USB 电源**，也可以用电脑 USB 口进行烧录和串口调试。此时不接市电 AC-DC 模块输入端，不将真实灯具市电回路接到面板；继电器保持断开或仅在安全低压负载下验证。

固件默认测试模式开启，测试时会跳过继电器输出。只有在隔离接口、继电器、供电、引脚映射和安装防护全部核实后，才进入真实负载验证。

### 屏幕备选

若保留现有 ESP32-S3 主控，可考虑 Waveshare `4.3inch Capacitive Touch LCD`（SKU 16249，RGB 800×480、40-pin FFC、I²C 触摸）。该方案需要核对具体开发板是否有足够的空闲 RGB 引脚，并自行匹配 FFC 转接、时序和电平；在主控板型号及原理图确认前，不建议按此备选采购。它与 H01 一体板二选一，不要同时购买。

## 3. 连接关系

### 低压供电与信号

```text
成品：隔离 AC-DC 5V 输出 ─→ 一体板 5V 输入
测试：5V USB-C 电源      ─→ 一体板 USB-C（烧录时连接电脑）

按钮 1 ─→ 隔离 DI1 ─┐
按钮 2 ─→ 隔离 DI2  ├─→ 可用板载输入 / 扩展 GPIO ─→ 固件三路开关逻辑
按钮 3 ─→ 隔离 DI3 ─┘

固件输出/扩展 GPIO ─→ 隔离继电器模块 IN1–IN3
```

4.3C 板载提供 2 路隔离数字输入和 2 路隔离开漏数字输出，三路实体开关与三路继电器不能简单视为已有足够的独立端口。应在模块选定后画出逐端子接线图：目前推荐用外接隔离 DI 和兼容的 GPIO 扩展补齐通道；GPIO 扩展端仍须符合逻辑电平并保留电气隔离边界。

一体板的 RGB 屏和触摸已在板上连接，无需另接 DSI/FFC 屏线。固件需后续集成 RGB LCD、触摸驱动和 LVGL；当前浏览器 HTML 预览不是 MCU 上的屏幕固件。

### 灯具市电回路

继电器触点按其 COM/NO/NC 规格切换对应灯具回路；交流线路的具体开断方式、保护、接地、线径和端子由合格电工根据现场电路设计。不要将灯具市电导线接入 ESP32 GPIO、板载数字输入、USB 或低压控制接口。继电器板载/外接开漏输出只能作为符合规格的低压控制接口，不能直接带灯具。

## 4. 固件与板级适配注意事项

- 工程当前 target 是 ESP32-S3，测试模式默认开启。
- 当前通用配置 GPIO4/5/6 是候选输入示例，继电器 GPIO 默认 `-1`（关闭）。这些值不是 4.3C 的最终引脚分配。
- 4.3C 上部分 GPIO 已被屏幕或触摸等板载功能使用；必须以该具体板卡原理图和官方引脚表重建 pin map，不能照用通用 ESP32-S3 DevKit 引脚图。
- 项目固件当前为 Matter 设备端；全屋 Matter 灯具汇总还需要 Matter Controller 或家庭中枢提供数据。
- 真实灯控启用前，先以 5V USB 完成 UI、按钮和 Matter 逻辑测试，再使用低压假负载测试继电器动作；市电负载最后由合格电工接入和验收。
