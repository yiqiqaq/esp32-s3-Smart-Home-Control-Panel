## ⚠️ v0.3 架构修正（关键）

核对 [Waveshare 4.3B 官方文档](https://docs.waveshare.com/ESP32-S3-Touch-LCD-4.3B)后确认：
**4.3B 没有外部 GPIO 排针**。它的对外接口只有：
- I2C 端子：VOUT(5V/3.3V 可选)、SDA=GPIO8、SCL=GPIO9（与触摸/RTC 共享总线）
- DI0/DI1：隔离数字输入（5~36V，经 CH422G）
- DO0/DO1：隔离开漏输出（经 CH422G，450mA 灌流）
- CAN / RS485 端子、USB-C（供电+烧录）、TF 卡、电池座

因此 v0.2 的"J2 直出 GPIO 控制继电器/读开关"**不成立**。v0.3 架构改为：

```
控制通道（全部经 I2C，GPIO8/9）：
  4.3B I2C 端子 ←──J2──→ 本板 MCP23017(U9)
    ├─ GPA0-2 → R4-6(330Ω) → Q1-3(S8050) → K1-3 继电器（替代原 J2.3-5 直驱）
    ├─ GPB0-2 ← U6-8 光耦 ← J3 干接点（开关输入改走 MCP，不再去 J5）
    └─ GPA3-7 → J6 备用扩展口
供电通道：
  本板 +5V 母线 → J2.1/2 → 自制 USB-C 线 → 4.3B USB-C 口
    （4.3B 无 5V 输入端子；其 I2C 端子 VOUT 是输出，禁止反向馈入）
  4.3B 自身 USB-C 调试供电与本板供电同时接入时：
    本板 Q4/Q5 理想二极管阻断向本板电源倒灌；4.3B 端 VBUS 双源并联，
    建议.调试时断开市电模式（README 供电规则）。
```

### J2/J5 重定义（v0.3）

| 排针 | 引脚定义 |
|---|---|
| J2（至 4.3B I2C 端子 + 供电） | 1=+5V(至4.3B USB-C), 2=GND, 3=SDA(GPIO8), 4=SCL(GPIO9), 5-8=GND |
| J5 | 1=+3V3, 2=GND, 3-7=备用(NC), 8=GND（v0.2 的 DI 直连功能取消） |
| J6（扩展口） | 1-3=RLY1-3(=GPA0-2，已占用), 4-8=GPA3-7 备用 |
| J3（干接点输入, 5.08 端子） | 1=IN1, 2=IN2, 3=IN3, 4=COM → 光耦 → MCP GPB0-2 |
| J4（灯具输出, 5.08 端子） | 1=N, 2=OUT1, 3=OUT2, 4=OUT3 |
| U10（USB Type-C 电源输入） | 仅取 5V（CC 5.1k 下拉已板载），经 Q5 与市电路径自动切换 |

**固件影响**：继电器/开关改走 MCP23017（I2C 0x20，INT 未接、采用轮询）。
工程内 `io_expander_service`（MCP23017 驱动）需启用；`PANEL_SWITCH_x_GPIO`/
`PANEL_RELAY_x_GPIO` 配置项由 MCP 通道替代。

## 隔离与爬电要求（评审第 2/5 步，IEC 60664-1）

工作电压按 250VAC 电网（300V 跨制），污染等级 2，材料组 IIIa（FR-4 CTI 175 起）：

| 绝缘类型 | 电气间隙 | 爬电距离 |
|---|---|---|
| 功能绝缘（L-N 之间） | 1.5mm | 3.2mm |
| 基本/附加绝缘（市电-SELV） | 1.5mm | 3.2mm |
| **加强绝缘（市电-SELV）** | **3.0mm** | **6.4mm** |

布线规则：
- AC_L / AC_L_F / AC_L_M / AC_N / AC_N_M / OUT1-3 对 SELV（+5V/+3V3/GND/所有逻辑线）
  按**加强绝缘 ≥6.4mm** 走线或开槽；L-N 之间按功能绝缘 ≥3.2mm；
- 继电器触点侧走线 ≥2mm；J4/J1 端子之间保持端子额定爬电；
- U1（HLK-20M05）与 L1、K1-3 为隔离边界元件，本体下方禁止走其它网络铜。

## 机械核对清单（评审第 5 步，86 盒装配）

- [ ] 板框到焊盘 ≥0.3mm（DRC 已列 14 项违规，v0.3 修复见下）
- [ ] 86 暗盒内深：典型 32~40mm——HLK-20M05 本体高约 24mm 为最高件，选盒前实测
- [ ] 固定柱位：Ø3.2mm × 孔距 60mm（居中）已按 86 标准预留
- [ ] J3/J4 端子出线方向：面板侧走线到灯具/开关的弯曲半径 ≥15mm，端子间距 5.08mm
- [ ] USB-C（U10）在板底边：调试线缆需盒外引出或仅台架使用
- [ ] 继电器吸合面、HLK 散热面与盒壁间隙 ≥5mm

## ✅ v0.3 修复已应用并验证（2026-10-06）
