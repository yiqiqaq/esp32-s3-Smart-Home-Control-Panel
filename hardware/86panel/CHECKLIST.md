> 🧑 = 必须人工确认/操作　🤖 = 可由 AI 脚本自动化（结合本清单上下文）
> 旧报告数据（194 项 PCB / 172 项原理图）为整改前基线，逐项复测后勾销。

## 〇、先恢复 DRC：解决"画布订阅未建立"

该报错 = 检查面板无法绑定到活动画布。按顺序排查：

1. 🧑 关闭多余窗口：当前有 **2 个 GUI 窗口**存活（99131dc6 / c2989dd1）。
   同一工程开两个窗口是此报错的常见诱因——只保留一个，另一个整个关闭。
2. 🧑 在保留的窗口里：**关闭工程 → 重新打开**（让画布重新挂载）。
3. 🧑 双击项目树中的原理图/PCB 文档，让文档标签页获得焦点（DRC 面板跟随当前画布）。
4. 🧑 若仍报错：**完全退出嘉立创客户端并重启**（清掉残留的会话状态），再开工程。
5. 🤖 若通过命令行/MCP 触发 DRC：先执行 `LCEDA-Pro activate` 聚焦窗口，
   并确认没有残留的无头会话（AI 已清理完毕，当前应为 0 个无头会话）。
6. 重跑 DRC，把**新报告**与旧基线（194/172 项）对比后按下列顺序处理。

## 市电隔离人工核算参数（IEC 60664-1）

需要人工确认的输入参数（查外壳与使用场景后填入）：

| 参数 | 本设计取值 | 人工确认点 |
|---|---|---|
| 工作电压 | 250VAC（相-中线，300V 表列） | 实际电网波动 |
| 污染等级 | PD2（家用封闭外壳） | 若冷凝/灰尘改 PD3 |
| 材料组 | IIIa（FR-4 CTI 175-400） | 用高 CTI 板可升组 |
| 海拔 | ≤2000m | 超出需间隙修正系数 |
| 绝缘类型 | 市电-SELV = 加强绝缘；L-N = 功能绝缘 | — |

**结果要求（PD2 / MG IIIa / 300V）**：
- 功能绝缘（L-N）：爬电 ≥3.2mm，间隙 ≥1.5mm
- 基本/附加绝缘：爬电 ≥3.2mm，间隙 ≥1.5mm
- **加强绝缘（市电-SELV）：爬电 ≥6.4mm，间隙 ≥3.0mm**
- 隔离槽宽 ≥1mm 时，爬电路径跨槽按间隙路径计（槽不能短于 1mm）
- 参考表：IEC 60664-1:2021 表 F.5（爬电）/ 表 1（间隙）；替代核对表 60950-1 表 2N

**需要人工测量/核实的具体位置**：
1. J1 端子 L-N 之间 ≥3.2mm（端子本体额定核对）
2. F1/RV1/C6/L1 走线对 GND 铺铜边界 ≥6.4mm
3. U1 输入脚（AC）对输出脚（±Vo）≥6.4mm（模块本体已认证，板面仍需满足）
4. K1-3 触点走线对线圈侧走线 ≥6.4mm（或触点-线圈依继电器 5kV 认证 + 板面基本绝缘）
5. J4 端子对 J2/J5/J6 排针 ≥6.4mm
6. AC 走线对板边 ≥2mm（机械）+ 阻焊定义复核

## "导入更新"差异查看与安全同步（评审第 4 步）

1. PCB 编辑器 → 菜单「设计 → 导入更新」→ 弹出**差异对话框**（勿直接点全部应用）。
2. 逐类核对预期差异（本轮应为）：
   - 网络重命名：RLY1-3 来源改为 MCP（U9.28/27/26）、SWB1-3 新增、
     AC_L_M/AC_N_M 新增、U1 焊盘网络变更；
   - 元件删除：U3/U4/U5/R1/R2/R3/D4/D5/J7（历史遗留，应显示为删除）；
   - 元件新增：Q4/Q5/R20/R21/R22/C6/L1；
   - J2/J5 引脚属性变化。
3. 出现**非预期项**（如元件误删、网络丢失）：先回原理图修复，再重新导入。
4. 勾选确认后应用 → `Ctrl+S` 保存 PCB → 重跑 DRC。
5. 网表复核：AI 可比对原理图网表基线（38 网络/161 引脚）与 PCB 焊盘网络。

## 86 盒机械核对清单（评审第 5 步）

- [ ] 板框 86×86mm 对外壳开口（面板窗口通常 68×68 开孔，边框遮蔽区 ≥9mm/边：
      摆放 LED/按键/屏开窗时避开）
- [ ] 固定柱：Ø3.2mm 孔 × 孔距 60mm 对准底盒螺柱；柱高与板上最高件（HLK-20M05 ≈24mm）
      不干涉，盒内深 ≥32mm
- [ ] 接线端子方向：J3/J4 出线朝向盒内进线孔；5.08mm 端子拆线空间 ≥10mm
- [ ] 导线弯曲空间：灯具线/开关线在端子前预留 ≥15mm 直线段 + 弯曲半径
- [ ] USB-C（U10）位于板底边：线缆出线方向与盒体无干涉（仅调试用）
- [ ] J2→4.3B 的 I2C/供电走线长度与走向（4.3B 叠装位置）
- [ ] 继电器吸合面、HLK 散热面距盒壁 ≥5mm
- [ ] 高低压分区与外壳金属件（如有）的距离

## 自动化能力说明

AI 可脚本化完成（工程空闲时）：
- 连通性网表比对（已建 38 网络基线，可复核 PCB 焊盘网络一致性）
- 焊盘-板框 / 焊盘-焊盘最小距离全板审计（输出违规清单及坐标）
- 共线重叠线段检测与去重（对应 B1 端点重叠）
- 指定网络的走线宽度审计（对应 A4）

必须人工完成：GUI DRC 复跑与逐条定位、隔离终核、机械实测、
外壳/端子额定核对、固件联调（MCP23017 驱动）、市电验收。
